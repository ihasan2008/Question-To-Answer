# QTA — Question To Answer

> **Learn Something New. One Question at a Time.**

QTA (Question To Answer) is a learning repository containing short, one-line questions and answers on a wide range of topics. Its goal is to build knowledge, improve memory, encourage curiosity, and make learning simple and consistent.

## 🎯 Purpose

- Learn new things through short questions and answers.
- Build General Knowledge across different subjects.
- Develop curiosity and critical thinking.
- Improve memory through regular practice.
- Create a growing collection of questions for lifelong learning.

## 📚 Question Categories

Questions may cover a wide range of topics, including:

- General Knowledge
- Bangladesh
- World & Geography
- Science & Nature
- Computer & Technology
- Programming & Web Development
- Mathematics & Logic
- History & Civilization
- Language & Literature
- Education & Everyday Life
- Sports & Culture
- Artificial Intelligence

## 📂 Repository Structure

```text
Question-To-Answer/
│
├── README.md
│
├── Question-To-Answer-1.md    # Questions 001–100
├── Question-To-Answer-2.md    # Questions 101–200
├── Question-To-Answer-3.md    # Questions 201–300
├── Question-To-Answer-4.md    # Questions 301–400
├── Question-To-Answer-5.md    # Questions 401–500
│
└── ...
```

Each file contains **100 consecutive questions and answers**. New files will be added as the collection grows.

## 📝 Question & Answer Format

Every question should be short, clear, and focused on a single piece of knowledge.

```md
# 01 - Question?
> Answer: Answer.
```

## 🔢 Numbering System

| File | Question Range |
|---|---:|
| `Question-To-Answer-1.md` | 001–100 |
| `Question-To-Answer-2.md` | 101–200 |
| `Question-To-Answer-3.md` | 201–300 |
| `Question-To-Answer-4.md` | 301–400 |
| `Question-To-Answer-5.md` | 401–500 |
| `...` | Continues in sequence |

**Rule:** Every question must have a unique, sequential number. Questions must not be duplicated unnecessarily, and numbering must continue from the previous file.

## ✅ Guidelines

1. Keep questions short and easy to understand.
2. Keep answers concise, preferably one line.
3. Include accurate and reliable information.
4. Use clear and consistent formatting.
5. Avoid unnecessary repetition.
6. Verify facts that may change over time.
7. Add questions from different subjects.
8. Continue numbering without skipping numbers.
9. Use the appropriate language for each question.
10. Update the collection regularly.

## 🚀 How to Use

1. Open a `Question-To-Answer` file.
2. Read a question carefully.
3. Try to answer it before reading the answer.
4. Check your answer.
5. Review questions you answered incorrectly.
6. Repeat regularly to strengthen your knowledge.

## 🌱 Growth Plan

QTA is designed to grow gradually, from 100 questions to 1,000, 10,000, and beyond.

Each new file will add another 100 questions, creating an organized and continuously expanding knowledge base.

## 📌 Core Principle

> **One Question. One Answer. One Step Forward.**

Learn continuously. Stay curious. Build knowledge one question at a time.
